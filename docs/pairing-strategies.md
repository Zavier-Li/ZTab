# 编排策略实现说明

本次沿用已确认的两种赛制，不自动替换现有赛程。

- 最优分层随机预排：默认最多交手两次时，通过可验证的均衡结构及随机变换，保证四轮每队九个不同对手、四辩位各一次。理论界限为54个不同队对。进一步搜索同校冲突，联合比较标准8个或深度32个分组候选，每个联合枚举1296种赛场分配，评价场地与预设裁判接触均衡；额外限制无法达到证明界限时必须如实报告，不能冒称全局最优。
- BP Power Match：首轮随机，之后累计队伍积分分池；不按辩手分机械切组。升池可进入整个上池，优先减少重复升池；匈牙利匹配优化历史辩位的 Shannon 熵成本，随机打乱等价解。等价主目标解中减少重复交手。记录种子、积分池、升池、辩位成本与重复交手。BP重复辩位是提醒而非非法赛程。
- 稳定性：保留历史数据；前序正式成绩未完整或尚有待确认正式草稿时禁止下一轮；已有后续轮次时锁定旧成绩；重置及JSON备份包含策略信息。
- 验证：固定种子、多种子、学校约束、54队对/每队9对手、四辩位、场地联合枚举、BP池定义与升池优先、辩手分独立、BP无解辩位案例、导入往返与构建。浏览器中已检查预排生成；BP完整现场流程由用户手动检查。
